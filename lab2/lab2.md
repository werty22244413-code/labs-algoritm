## Код программы

```cpp
#include <iostream>
#include <queue>
#include <chrono>

using namespace std;
using namespace chrono;

// Базовый уровень: Шаблонная функция
// Возвращает элемент массива по индексу или значение по умолчанию
template <typename T>
T getOrDefault(T arr[], int n, int index, T defaultValue) {
    return (index >= 0 && index < n) ? arr[index] : defaultValue;
}

// Продвинутый уровень: Шаблонный класс FixedQueue
// Кольцевой буфер фиксированного размера N
template <typename T, int N>
class FixedQueue {
    T data[N];
    int head = 0, tail = 0, count = 0;
public:
    // O(1)
    bool enqueue(const T& val) { 
        if (isFull()) return false;
        data[tail] = val;
        tail = (tail + 1) % N;
        count++;
        return true;
    }
    
    // O(1)
    bool dequeue() { 
        if (isEmpty()) return false;
        head = (head + 1) % N;
        count--;
        return true;
    }
    
    // O(1)
    T front() const { 
        return data[head]; 
    }
    
    // O(1)
    bool isEmpty() const { 
        return count == 0; 
    }
    
    // O(1)
    bool isFull() const { 
        return count == N; 
    }
};

// Точка входа
int main() {
    // Демонстрация работы getOrDefault
    int arr[] = {10, 20, 30};
    cout << "--- getOrDefault ---" << endl;
    cout << "getOrDefault(1): " << getOrDefault(arr, 3, 1, -1) << endl;
    cout << "getOrDefault(5): " << getOrDefault(arr, 3, 5, -1) << endl << endl;

    // Демонстрация работы FixedQueue
    cout << "--- FixedQueue ---" << endl;
    FixedQueue<int, 3> q;
    q.enqueue(1); 
    q.enqueue(2); 
    q.enqueue(3); 
    q.enqueue(4); // 4 не добавится, так как очередь заполнена
    
    cout << "Front: " << q.front() << endl;
    q.dequeue();
    cout << "Front after dequeue: " << q.front() << endl << endl;

    // Экспериментальное сравнение (замер вставки/извлечения 1 млн элементов)
    cout << "--- Сравнение с STL ---" << endl;
    const int TEST_N = 1000000;
    auto start = high_resolution_clock::now();
    
    queue<int> stl_q;
    for(int i = 0; i < TEST_N; i++) { 
        stl_q.push(i); 
        stl_q.pop(); 
    }
    
    auto end = high_resolution_clock::now();
    cout << "Time std::queue: " << duration_cast<microseconds>(end - start).count() << " mks" << endl;

    return 0;
}
```

**1. Что такое О-нотация (Big O) и зачем она нужна?**
Математическая нотация для описания асимптотического поведения алгоритма (роста времени выполнения или потребления памяти при увеличении объема входных данных). Нужна для оценки масштабируемости и сравнения эффективности алгоритмов, игнорируя константы и особенности конкретного железа.

**2. Какая сложность у доступа к элементу массива по индексу? Почему?**
**O(1)**. Массив занимает непрерывный блок памяти, поэтому адрес любого элемента вычисляется за одну арифметическую операцию: `адрес_начала + (индекс * размер_элемента)`.

**3. Какая сложность у бинарного поиска? Почему?**
**O(log n)**. На каждом шаге область поиска делится ровно пополам, что требует логарифмического количества операций для нахождения элемента.

**4. Что означает сложность O(n log n)? Приведите пример алгоритма.**
Линейно-логарифмическая сложность. Обычно возникает, когда нужно выполнить операцию O(log n) для каждого из n элементов. 
*Пример*: эффективные алгоритмы сортировки (Merge Sort, Quick Sort, Heap Sort).

**5. Что такое амортизированный анализ? Приведите пример.**
Оценка средней стоимости *последовательности* операций, когда редкие дорогие операции «размазываются» на множество дешёвых. 
*Пример*: `push_back` в `std::vector` имеет амортизированную O(1), несмотря на то, что иногда происходит перевыделение памяти за O(N).

**6. Какая сложность у двух вложенных циклов по n итераций каждый?**
**O(n²)**. Внутренний цикл выполняется n раз для каждой из n итераций внешнего цикла (n * n).

**7. Какая сложность у рекурсивного вычисления чисел Фибоначчи?**
**O(2ⁿ)** (экспоненциальная) для наивной рекурсии без мемоизации, так как каждое вычисление порождает два новых вызова. *(С мемоизацией или в итеративном виде — O(n)).*

**8. Что такое шаблоны функций? Как их объявить и использовать?**
Функции, которые могут работать с разными типами данных.
* **Объявление**: `template <typename T> T max(T a, T b) { return a > b ? a : b; }`
* **Использование**: `max<int>(1, 2)` или просто `max(1, 2)` (компилятор сам выведет тип).

**9. Что такое шаблоны классов? Как их объявить и использовать?**
Классы, параметризованные типами данных.
* **Объявление**: `template <typename T> class Stack { T data; /*...*/ };`
* **Использование**: `Stack<int> myStack;` (создание объекта для конкретного типа).

**10. В чём преимущество шаблонов перед перегрузкой функций?**
Шаблоны позволяют написать **один** универсальный алгоритм для любых типов данных, избегая дублирования кода, которое неизбежно возникает при написании десятков перегруженных функций.

**11. Как указать, что шаблонный параметр - тип?**
С помощью ключевых слов `typename` или `class` в угловых скобках: `template <typename T>` или `template <class T>`.

**12. Можно ли создать шаблон с несколькими параметрами типов?**
**Да**. Пример: `template <typename T, typename U> class Pair { T first; U second; };`.
